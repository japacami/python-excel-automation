# 🐍 Python Automation — Vendas Excel

Automação em Python para leitura e processamento de dados de vendas a partir de arquivos Excel.

## 📋 Descrição:

Este projeto lê uma planilha de vendas (`Vendas.xlsx`), processa os dados utilizando a biblioteca pandas e gera análises/relatórios automaticamente para o e-mail.

## 🚀 Tecnologias utilizadas:

- Python 3.14;
- pandas;
- pywin32;
- openpyxl;
